## NegooxTools:  My first project dedicated to managing small entrepreneurs' products simply and efficiently


## About this project
- Get realtime currency selected using Retrofit and show to screen by a Dialog Component, where on it you can calculate the currency selected on actual dolar price and vice versa.
- Profile system using DataStore and SharedPreferences to save, update and delete Profiles.
- Aproximate Calculate for Calculate Product cost by the price and Weight using selected Profile for Calculate additional Taxes and Cost to final Product cost.
- Product list to show in RecyclerView the list of the products from the DataBase using SQLite3, FAB component to add new Products to DataBase, Search Component to find products and Chips Components operating as Filters
- Statistics using lib MPAndroidChart to show on Barchart products solds by week,month and year, piechar to show profit and cost by week, month and year,
and top3 ranking of products by the most profit, the most quick on sell, the fastest on arrive, etc, using tabview and viewPager2 Components with fragments.

## Working on this project with:
- Kotlin
- XML
- Retrofit
- DataStore/SharedPreferences
- Gson
- TabView and ViewPager2
- MpAndroidCharts
- SQLite3
